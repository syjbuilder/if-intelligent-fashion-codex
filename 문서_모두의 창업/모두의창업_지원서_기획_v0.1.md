## Q2. 아이디어를 떠올린 배경 이야기를 들려주세요. (필수)

- **글자 수 제한: 1000자**
- 사진 추가 가능 (선택, Q2~Q4 합산 최대 5장)

### 작성 내용 (현재 680자 / 1000자)
```
AI 기술은 빠르게 발전하고 있지만, 모든 기술 발전이 사람들의 삶을 더 편하게 만드는 것은 아니라고 생각합니다. 키오스크와 온라인 주문 시스템은 효율을 높였지만, 일부 시니어에게는 오히려 주문과 소비를 더 어렵게 만들었습니다. 저는 기술이 사람의 삶에 실제 가치를 더할 때 의미가 있다고 생각합니다.

의류 쇼핑도 비슷한 문제를 겪고 있습니다. 통계청에 따르면 2024년 온라인쇼핑 거래액은 242조 원을 넘었고, 이 중 모바일쇼핑이 75.3%를 차지했습니다. 의복 역시 온라인에서 큰 거래 규모를 가진 카테고리입니다. 동시에 국세청 자료에 따르면 통신판매업 사업자 수는 2018년 대비 148.4% 늘어 100대 생활업종 중 1위(2023년 말 기준 약 60.7만 명)가 되었습니다. 판매자와 상품은 폭발적으로 늘었지만, 옷은 원래 직접 보고 입어보며 선택하던 제품이라 소비자는 수많은 상품 속에서 오히려 원하는 옷을 찾기 어려워졌습니다.

동시에 K팝, K뷰티, 패션, 외모 관리에 대한 관심은 커지고 있고, 사람들은 옷을 통해 자기 개성을 표현하고 싶어 합니다. 저는 이 정보 과잉 속에서 사용자가 말하듯 원하는 스타일을 입력하면 AI가 이를 룩으로 보여주고, 실제 구매 가능한 상품으로 연결해주는 서비스를 만들고 싶었습니다. 'Wear what you imagine.' 이것이 I.F.를 떠올린 배경입니다.
```

## Q3. 아이디어는 누구의 어떤 문제를 해결해주나요? (필수)

- **글자 수 제한: 1000자**
- 사진 추가 가능 (선택, Q2~Q4 합산 최대 5장)

### 작성 내용 (현재 603자 / 1000자)
```
I.F.는 온라인 의류 쇼핑에서 원하는 옷을 찾기 어려운 소비자의 문제를 해결합니다.

초기 대상은 20~30대 여성 패션 소비자입니다. 이들은 무신사, 29CM, 지그재그, 에이블리, 네이버 쇼핑, 브랜드 자사몰 등 여러 플랫폼을 오가며 쇼핑하지만, 원하는 스타일을 정확한 검색어로 표현하기 어렵고, 너무 많은 상품 속에서 선택 피로를 느낍니다.

예를 들어 사용자는 "여름 데이트에 입을 꾸안꾸 룩", "하체가 커버되는 출근룩", "좋아하는 인플루언서 느낌의 옷"처럼 자연스럽게 생각하지만, 기존 쇼핑몰 검색창은 이런 표현을 충분히 이해하지 못합니다.

기존 쇼핑몰의 AI 검색, 이미지 검색, 가상 피팅 기능은 대부분 자사 플랫폼 안의 상품을 더 잘 팔기 위해 만들어졌습니다. I.F.는 특정 쇼핑몰 안에 갇히지 않고, 여러 브랜드와 쇼핑몰을 가로지르는 독립형 AI 탐색 레이어로 동작한다는 점에서 다릅니다. 더 많은 상품을 보여주는 것이 아니라, 사용자가 원하는 방향으로 선택지를 좁혀줍니다.

장기적으로는 온라인 의류몰 접근이 어려운 시니어와 디지털 쇼핑에 익숙하지 않은 사용자에게도 도움이 되는, 말로 옷을 찾는 접근성 높은 AI 패션 탐색 도구로 확장하고 싶습니다.
```

## Q4. 아이디어를 어떻게 실현하고 싶으신가요? (필수)

- **글자 수 제한: 1000자**
- 사진 추가 가능 (선택, Q2~Q4 합산 최대 5장)

### 작성 내용 (현재 740자 / 1000자)
```
먼저 웹 기반 MVP로 시작하되, 국내 패션 소비의 75% 이상이 모바일에서 일어난다는 점을 고려해 모바일 웹 경험을 핵심 검증 범위에 두고, 데스크톱은 더 넓은 작업 공간으로 보완합니다. 향후 앱 전환이 가능하도록 프론트엔드와 백엔드를 분리한 API-first 구조로 설계합니다.

사용자는 로그인 후 텍스트 프롬프트를 입력하고, AI는 1~3개의 패션 룩 이미지를 생성합니다. 룩을 클릭하면 어울리는 실제 상품 링크와 유사 상품을 볼 수 있습니다.

초기에는 모든 온라인몰을 자동 연동하기보다, 전체 룩 기준 약 500개의 curated look DB를 직접 구축해 검증합니다. 각 룩에는 프롬프트, AI 생성 이미지, 계절·상황·무드·색상·핏·구성 아이템·실제 구매 링크가 함께 저장됩니다. 1인 창업자가 AI 에이전트와 바이브코딩을 활용해 개발 부담을 줄이는 방식으로 V0를 실행합니다.

로그인은 Google을 기본으로 하되 국내 사용자를 위해 Kakao, Naver를 함께 제공합니다. 수익모델은 월구독과 토큰 방식이며, 무료 사용자는 제한된 생성·저장을, 유료 사용자는 더 많은 검색·저장과 고급 필터를 이용합니다. 이미지 업로드 기반 유사 상품 검색은 V0 이후 유료 확장 기능으로 단계적으로 도입합니다.

성공 지표는 룩 클릭률, 구매 링크 클릭률, 결과 저장률, 7일 재방문율로 측정합니다. 장기적으로는 공개 저장된 룩을 기반으로 다른 사용자가 참고할 수 있는 커뮤니티형 탐색 공간으로 확장하고 싶습니다.
```

## 사진 첨부 계획 (Q2~Q4 합산 최대 5장)

| 슬롯 | 위치 | 제안 이미지 | 비고 |

| 1 | Q2 | 정보 과잉 시각화 (쇼핑몰/상품 다양성) 또는 통신판매업 증가 그래프 | 신규 제작 필요 |
