## Q2. 아이디어를 떠올린 배경 이야기를 들려주세요. (필수)

- **글자 수 제한: 1000자**
- 사진 추가 가능 (선택, Q2~Q4 합산 최대 5장)

### 작성 내용
```
AI 기술은 빠르게 발전하고 있지만, 모든 기술 발전이 사람들의 삶을 더 편하게 만드는 것은 아니라고 생각합니다. 키오스크와 온라인 주문 시스템은 효율을 높였지만, 일부 시니어에게는 오히려 주문과 소비를 더 어렵게 만들었습니다. 저는 기술이 사람의 삶에 실제 가치를 더할 때 의미가 있다고 생각합니다.

의류 쇼핑도 비슷한 문제를 겪고 있습니다. 온라인 쇼핑 시장은 커졌고, 통계청에 따르면 2024년 온라인쇼핑 거래액은 242조 원을 넘었습니다. 의복 역시 온라인에서 큰 거래 규모를 가진 카테고리입니다. 그러나 옷은 원래 직접 보고 입어보며 선택하던 제품인데, 온라인몰과 브랜드가 많아지면서 소비자는 수많은 상품 속에서 오히려 원하는 옷을 찾기 어려워졌습니다.

동시에 K팝, K뷰티, 패션, 외모 관리에 대한 관심은 커지고 있고, 사람들은 옷을 통해 자기 개성을 표현하고 싶어 합니다. 저는 이 정보 과잉 속에서 사용자가 말하듯 원하는 스타일을 입력하면 AI가 이를 룩으로 보여주고, 실제 구매 가능한 상품으로 연결해주는 서비스를 만들고 싶었습니다. 이것이 I.F.를 떠올린 배경입니다.
```

## Q3. 아이디어는 누구의 어떤 문제를 해결해주나요? (필수)

- **글자 수 제한: 1000자**
- 사진 추가 가능 (선택, Q2~Q4 합산 최대 5장)

### 작성 내용
```
I.F.는 온라인 의류 쇼핑에서 원하는 옷을 찾기 어려운 소비자의 문제를 해결합니다.

초기 대상은 20~30대 여성 패션 소비자입니다. 이들은 무신사, 29CM, 지그재그, 에이블리, 네이버 쇼핑, 브랜드 자사몰 등 여러 플랫폼을 오가며 쇼핑하지만, 원하는 스타일을 정확한 검색어로 표현하기 어렵고, 너무 많은 상품 속에서 선택 피로를 느낍니다.

예를 들어 사용자는 "여름 데이트에 입을 꾸안꾸 룩", "하체가 커버되는 출근룩", "좋아하는 인플루언서 느낌의 옷"처럼 자연스럽게 생각하지만, 기존 쇼핑몰 검색창은 이런 표현을 충분히 이해하지 못합니다.

I.F.는 사용자의 프롬프트를 계절, 상황, 무드, 색상, 핏, 예산 등으로 해석하고 AI 룩 이미지로 시각화한 뒤, 실제 구매 가능한 상품과 연결합니다. 즉 더 많은 상품을 보여주는 것이 아니라, 사용자가 원하는 방향으로 선택지를 좁혀줍니다.

장기적으로는 온라인 의류몰 접근이 어려운 시니어와 디지털 쇼핑에 익숙하지 않은 사용자에게도 도움이 되는 AI 패션 탐색 도구로 확장하고 싶습니다.
```

## Q4. 아이디어를 어떻게 실현하고 싶으신가요? (필수)

- **글자 수 제한: 1000자**
- 사진 추가 가능 (선택, Q2~Q4 합산 최대 5장)

### 작성 내용
```
먼저 웹 기반 MVP로 시작하려고 합니다. 사용자는 로그인 후 텍스트 프롬프트를 입력하고, AI는 이를 바탕으로 1~3개의 패션 룩 이미지를 생성합니다. 사용자가 룩 이미지를 클릭하면 해당 룩과 어울리는 실제 상품 링크와 유사 상품을 볼 수 있습니다.

초기에는 모든 온라인몰을 자동 연동하기보다, 전체 룩 기준 약 500개의 curated look DB를 직접 구축해 검증하려고 합니다. 각 룩에는 프롬프트, AI 생성 이미지, 계절, 상황, 무드, 색상, 핏, 구성 아이템, 실제 구매 링크를 함께 저장합니다. 이를 통해 프롬프트 → AI 룩 → 실제 상품 추천 흐름이 작동하는지 확인할 계획입니다.

서비스는 데스크톱 우선 반응형 웹으로 만들고, Google 로그인을 기본으로 하되 국내 사용자를 위해 Kakao, Naver 로그인도 고려합니다. 수익모델은 월구독과 토큰 방식을 생각하고 있습니다. 무료 사용자는 제한된 생성과 저장을 이용하고, 유료 사용자는 더 많은 검색, 저장, 이미지 업로드 기반 유사 상품 검색, 향후 개인화 기능을 이용할 수 있습니다.

장기적으로는 공개 저장된 룩을 기반으로 다른 사용자가 참고할 수 있는 커뮤니티형 탐색 공간까지 확장하고 싶습니다.
```
