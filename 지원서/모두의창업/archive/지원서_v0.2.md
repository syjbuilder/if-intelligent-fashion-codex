## Q2. 아이디어를 떠올린 배경 이야기를 들려주세요. (필수)

- **글자 수 제한: 1000자**
- 사진 추가 가능 (선택, Q2~Q4 합산 최대 5장)

### 작성 내용 (610자 / 1000자)
```
저는 옷을 사고 싶을 때마다 어느 앱을 켜야 할지부터 헷갈렸습니다. 무신사, 29CM, 지그재그, 에이블리, 네이버 쇼핑, 브랜드 자사몰까지 들여다봐야 했고, 검색을 시작해도 결국 보이는 건 마케팅 순서대로 정렬된 상품들뿐이었습니다. 내가 한 소비가 합리적이었는지, 비슷한 상황에 다른 사람은 어떤 옷을 입는지 비교할 길이 없었고, 머릿속에 떠오른 '이런 느낌'을 실제 옷으로 옮겨주는 도구는 어디에도 없었습니다. 트렌드는 노출되는 대로 따라가게 되었습니다.

이 문제는 시장 규모 측면에서도 분명합니다. 통계청에 따르면 2024년 온라인쇼핑 거래액은 242조 원을 넘었고 이 중 모바일이 75.3%를 차지하며, 국세청 자료에서는 통신판매업 사업자 수가 2018년 대비 148.4% 늘어 100대 생활업종 중 1위(2023년 말 약 60.7만 명)가 되었습니다. 판매자와 상품은 폭증했지만, 사용자가 자기 상상에 가까운 옷을 찾는 도구는 그 속도를 따라오지 못했습니다.

저는 사용자가 말하듯 원하는 스타일을 입력하면 AI가 이를 룩으로 보여주고, 실제 구매 가능한 상품으로 연결해주는 서비스를 만들고 싶었습니다. 'Wear what you imagine.' 이것이 I.F.의 출발점입니다.
```

## Q3. 아이디어는 누구의 어떤 문제를 해결해주나요? (필수)

- **글자 수 제한: 1000자**
- 사진 추가 가능 (선택, Q2~Q4 합산 최대 5장)

### 작성 내용 (639자 / 1000자)
```
I.F.는 온라인 의류 쇼핑에서 원하는 옷을 찾기 어려운 소비자의 문제를 해결합니다.

대상은 20~30대 여성 패션 소비자입니다. 이들은 무신사, 29CM, 지그재그, 에이블리, 네이버 쇼핑, 브랜드 자사몰 등 여러 플랫폼을 오가며 쇼핑하지만, 원하는 스타일을 정확한 검색어로 표현하기 어렵고, 너무 많은 상품 속에서 선택 피로를 느낍니다.

예를 들어 사용자는 "여름 데이트에 입을 꾸안꾸 룩", "하체가 커버되는 출근룩", "좋아하는 인플루언서 느낌의 옷"처럼 자연스럽게 생각하지만, 기존 쇼핑몰 검색창은 이런 표현을 충분히 이해하지 못합니다. 또 검색 결과는 대부분 마케팅 노출 순서대로 정렬되어, 사용자가 자기 상상에 더 가까운 선택지를 발견하기 어렵습니다.

기존 쇼핑몰의 AI 검색, 이미지 검색, 가상 피팅 기능은 대부분 자사 플랫폼 안의 상품을 더 잘 팔기 위해 만들어졌습니다. I.F.는 특정 쇼핑몰 안에 갇히지 않고, 여러 브랜드와 쇼핑몰을 가로지르는 독립형 AI 탐색 레이어로 동작한다는 점에서 다릅니다. I.F.가 대체하는 것은 쇼핑몰의 검색창이 아니라, 사용자가 무신사·인스타·핀터레스트를 오가며 영감을 모으던 '둘러보기' 시간이며, 더 많은 상품을 보여주는 것이 아니라 사용자가 원하는 방향으로 선택지를 좁혀줍니다.
```

## Q4. 아이디어를 어떻게 실현하고 싶으신가요? (필수)

- **글자 수 제한: 1000자**
- 사진 추가 가능 (선택, Q2~Q4 합산 최대 5장)

### 작성 내용 (925자 / 1000자)
```
먼저 웹 기반 MVP로 시작하되, 국내 패션 소비의 75% 이상이 모바일에서 일어난다는 점을 고려해 모바일 웹 경험을 핵심 검증 범위에 두고, 데스크톱은 더 넓은 작업 공간으로 보완합니다. 향후 앱 전환이 가능하도록 프론트엔드와 백엔드를 분리한 API-first 구조로 설계합니다. 사용자는 로그인 후 텍스트 프롬프트를 입력하고, AI는 1~3개의 패션 룩 이미지를 생성하며, 룩을 클릭하면 어울리는 실제 상품 링크와 유사 상품을 볼 수 있습니다.

데이터는 단계적으로 확장합니다. V0에서는 1인이 직접 큐레이션한 약 500개의 룩 DB로 매칭 품질을 검증하고, V1에서는 사용자 클릭·저장·피드백 데이터로 자동 태깅 비중을 늘려 큐레이션을 효율화하며, V2에서는 어필리에이트 네트워크와 브랜드 자사몰 제휴로 카탈로그를 확장합니다. AI 이미지가 비현실적일 경우 'wearable version'으로 완화하고, 사용자의 '비슷하지 않음' 피드백을 매칭 품질 개선에 직접 반영합니다.

저는 이미 V0의 PRD, 와이어프레임, 웹 디자인 초안을 직접 작성했고, AI 에이전트와 바이브코딩으로 프론트엔드 구현을 진행 중입니다. 기획·디자인·개발 전 과정에 AI 도구를 도입해 1인 창업의 한계를 보완하는 구조를 만들었습니다.

로그인은 Google을 기본으로 Kakao, Naver를 함께 제공합니다. 수익모델은 월구독과 토큰 방식이며, 무료 사용자는 제한된 생성·저장을, 유료 사용자는 더 많은 검색·저장과 고급 필터를 이용합니다. 이미지 업로드 기반 유사 상품 검색은 V0 이후 유료 확장 기능으로 단계적으로 도입합니다. 첫 100명 사용자는 제가 운영하는 인스타그램과 쓰레드 계정을 통해 패션에 관심 있는 20~30대에게 데모 프롬프트와 룩 결과를 공유하며 확보합니다. 성공 지표는 룩 클릭률, 구매 링크 클릭률, 결과 저장률, 7일 재방문율입니다.
```
