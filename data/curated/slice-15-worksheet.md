# 슬라이스 큐레이션 워크시트 — 15룩 × 실상품 (Stage 1용)

> **이 문서는 안내서입니다. 실제 작성은 같은 폴더의 `slice-15-products-fill.csv`(구글 시트)에서 합니다.**
> 목적: "핵심 루프(말 → 룩 → 진짜 상품)"를 작게 증명할 **15개 룩**에, 각각 **실제로 살 수 있는 상품 3~5개**를 연결한다.
> 결정 근거: `docs/ADR.md` ADR-020 · `docs/AI_PIPELINE.md` §9 수집 SOP.

---

## 역할 분담

| 누가 | 무엇을 |
|---|---|
| **PO(사용자분)** | 15개 룩 각각에 어울리는 **진짜 상품을 직접 고르고**, 상품마다 **품목 · 상품명 · 구매링크 · 이미지링크 · 가격 · 플랫폼**을 채운다. |
| **AI(저)** | 룩 컨셉·스타일 의도·태그(상황/무드/색/핏/계절)는 **이미 채워 둠**. PO가 상품을 채우면 → enum 태깅·상품 캡션·룩↔상품 연결·시드 적재를 AI가 처리. 애매한 분류는 PO 품목 표기를 보고 확정. |

→ **사용자분이 채울 칸 6개**: 품목 / 상품명 / 구매링크URL / 이미지URL / 가격 / 플랫폼.

---

## 채울 칸 설명

1. **품목(직접)** — 치마 · 바지 · 원피스 · 자켓 · 가디건 · 니트 · 블라우스 · 코트 · 바람막이 등, **실제 고른 품목**을 적기. (제가 이걸로 카테고리=상의/하의/원피스/아우터와 세부 태그를 정확히 잡습니다. "가디건"처럼 애매한 건 이 표기가 결정적.)
2. **상품명** — 몰에 표기된 상품명 그대로.
3. **구매링크 URL** — 몰 홈 말고 **그 상품 상세페이지** 주소. 예: `https://www.29cm.co.kr/products/123456`
4. **이미지 URL** — 상세페이지 대표 이미지를 **우클릭 → "이미지 주소 복사"**. (15개라 직접 넣는 게 정확. 안 뜨면 임시 이미지로 자동 대체.)
5. **가격(원)** — 현재 판매가(할인가면 할인가). 숫자만.
6. **플랫폼** — 정확히 셋 중 하나: `29CM` · `MUSINSA` · `브랜드자사몰`. (지그재그·에이블리 등은 이번 슬라이스 제외)

> 규칙: 실제 판매 중인 상품만 · 룩당 3~5개(메인 구성은 필수, 4~5번째 관련/유사는 선택).

## 구글 시트로 작성하는 법

1. Google Sheets → **파일 → 가져오기(Import) → 업로드** → `slice-15-products-fill.csv` 선택 → "스프레드시트 바꾸기"로 가져오기.
2. 빈 칸(품목·상품명·구매링크URL·이미지URL·가격원·플랫폼)을 채운다. (맨 앞 `슬롯_가이드` 열은 참고용 — 그대로 두기)
3. 다 채우면 → **파일 → 다운로드 → 쉼표로 구분된 값(.csv)**.
4. 받은 파일을 `C:\dev\if\data\curated\slice-15-products-fill.csv` 에 같은 이름으로 덮어쓰기 → 저에게 "다 했어"라고 알려주세요. 제가 읽어 진행합니다.
   - 덮어쓰기가 번거로우면 **채운 표 내용을 채팅에 붙여넣어 주셔도** 됩니다.

# 15개 룩 브리프 (CSV의 행 구성)

## 다 채우신 뒤 (AI가 할 일)

1. 품목 표기 기준으로 카테고리(상의/하의/원피스/아우터) + enum 태깅(색·핏·소재·무드·계절·상황) + 캡션 2종 초안 → PO 스팟체크.
2. 룩↔상품 연결(메인 조합/유사/관련) + 이미지(주신 URL, 안 뜨면 placeholder) 연결.
3. `src/lib/seed/`의 in-repo 시드로 적재 → 매칭기·스튜디오 배선(Stage 1).
4. 일부러 안 맞는 데모("피크닉 가는 스트릿룩")로 fallback 검증 → 평가셋(Stage 2)으로 적중률 측정.

> 커버리지: 이 15룩은 데모 프롬프트(봄 데이트 파스텔 / 출근 뉴트럴 / 주말 스포티 / 하객 미디드레스 / 장마 레이어드)를 모두 포함하고, 상황·무드·색·핏·계절을 고루 분포(피크닉·스트릿 제외).
