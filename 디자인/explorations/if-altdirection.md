## 1. 한 줄 컨셉
v0.7가 **"조용한 muted 에디토리얼"**이라면, 이 방향은 **"시네마틱·생성적·타이포 주도의 AI 아틀리에"**.
AI를 숨기지 않고 **우아하게 살아있게** 만들고, 프롬프트(상상) 자체를 인터페이스의 주인공으로 세운다.

## 2. 서비스에서 도출한 디자인 논리 (docs만 보고)
- **핵심 가치 = 상상 → 룩 → 구매**(PRD). 그래서 화면의 주어를 "상품 그리드"가 아니라 **"상상하는 문장"**으로 잡았다 → hero가 살아있는 프롬프트.
- **하이브리드 생성**(AI_PIPELINE: 큐레이션 DB 우선 + 실시간 생성). 그래서 "생성"을 **실(thread)이 실루엣으로 직조되는 모먼트**로 시각화 — AI가 일하는 순간을 브랜드 경험으로.
- **여러 몰을 가로지르는 독립 레이어**(브랜드). 그래서 결과 화면은 한 몰의 상품 리스트가 아니라, **룩 위로 상품이 떠오르는(surfacing) 갤러리**.
- **데일리·한국 20-30 여성**. 그래서 압도적 럭셔리가 아니라 **다가갈 수 있는 우아함**(따뜻한 ivory·champagne) + 구매 근접성 유지.

## 3. 아트디렉션 디테일
- **팔레트**: obsidian(#0b0b0f) + warm ivory(#f4efe6) + 단일 luminous **champagne #e6c08a**. 생성 모먼트에만 **cool glow #8f93ff**(지성/AI) — 따뜻함(패션)과 차가움(AI)의 듀오톤 긴장.
- **타이포**: 에디토리얼 세리프 **Fraunces**(상상의 문장·헤드라인, 가는 weight 300~400 + italic 강조) + **Inter/Pretendard**(UI). v0.7의 Inter 단일과 달리 **세리프의 표현력**을 전면에.
- **레이아웃**: 풀블리드 내러티브 스크롤 3막 — **Imagine(hero) → Making(weaving) → Wear(results)** + closing. 좌측 시작선·번호 시스템(01/i·ii·iii).
- **모션(시네마틱·절제)**: 커서 글로우 + 자석 CTA + 카드 tilt + smooth scroll(Lenis) + 단어 모핑 프롬프트 + 스크롤 동기 line-draw(weaving) + reveal-words. overshoot 바운스·과시 3D 없음.
- **결과 인터랙션**: 룩 plate hover → 상품 패널 surfacing(상품명·브랜드·₩가격·외부 구매 = `aria-disabled` placeholder, ADR-004).

**트레이드오프 요약**: 트랙 B는 **브랜드 각인과 차별화**가 강하지만, (1) 성능(모션·폰트), (2) 접근성/모바일, (3) 구현·유지비용,
(4) 기존 "AI는 조용하게" 철학과의 긴장이 비용이다. V0 전체를 이걸로 가기보다는 **요소를 골라 포팅**하는 게 현실적.

## 6. 트랙 A(프로덕션)로 가져올 만한 요소 — 추천 5
1. **살아있는 프롬프트 hero(단어 모핑)** — Explore/랜딩 진입의 "상상 유도"를 강화(빈 입력창 마비 방지와 정확히 합치). ★ 가장 추천.
2. **생성 모먼트 = 실 직조(line-draw)** — 현재 LoadingScene의 옷걸이 SVG를 "weaving" 라인드로우로 격상(브랜드 시그니처).
3. **결과 plate hover → 상품 surfacing** — 룩 우선 + 구매 근접을 동시에. (현 드로어/패널과 병행 가능)
4. **세리프 액센트(Fraunces)를 헤드라인 한정 도입** — Inter 단일에 표현력 한 스푼(단, 7원칙·weight 규칙과 협의 필요).
5. **커서/매그네틱/스무스스크롤 '손맛'** — 데스크톱 한정, prefers-reduced-motion·모바일 가드로 절제 적용.

> 포팅 시 모두 **제품 가드(사람 0·외부링크·V0 범위)**와 **성능·접근성** 안에서 재단해야 한다. 이 데모는 "어디까지 갈 수 있나"의 상한선을 보여줄 뿐.
