## 목표

사용자가 텍스트 프롬프트로 상상한 패션 스타일을 AI 룩 이미지로 시각화하고, 그 룩과 어울리는
실제 구매 가능한 국내 패션 상품으로 연결한다. "원하는 스타일은 있지만 어떤 검색어로 찾을지
모르는" 탐색 문제를 해결한다.

## 사용자

- 한국 20-30대 여성 패션 소비자
- 무신사·29CM·지그재그·에이블리·네이버쇼핑·브랜드 자사몰을 오가며 온라인 쇼핑
- 인스타그램·유튜브·핀터레스트에서 영감을 받지만 탐색 피로를 느낌
- 1인 창업자가 AI 에이전트와 함께 실행 가능한 수준으로 V0 범위를 제한

## 핵심 기능 (V0 Core)

1. **Explore 진입 피드** — Get Started 후 첫 화면은 빈 입력창이 아닌 큐레이션 룩 6-12개 + 시즌 데모 프롬프트 3-5개. "빈 입력창 마비" 방지. 룩 카드 클릭 시 그 프롬프트 자동 입력 후 워크스페이스 진입.
2. **프롬프트 입력** — 자유 텍스트 + 보조 칩(상황/계절/무드/예산/핏). 칩 클릭은 silent filter가 아닌 **새 conversation turn**(AI가 의도 보정해 재검색·생성).
3. **AI 룩 생성** — 프롬프트를 의도·상황·무드·아이템으로 해석해 1-3개 룩 이미지 생성. **curated 검색(B-path, ~90%) 우선 + AI 실시간 생성(A-path, ~10% fallback)** 하이브리드. 결과 카드별 **'다시 생성'** 액션. 로딩 중 진행 텍스트("○○○○ 룩을 그리고 있어요") 노출 — 빈 화면 금지.
4. **상품 추천/연결** — 룩 클릭 시 상품 패널 오픈. curated look DB(500개) 기반으로 메인 추천 상품 조합 + 유사 상품 + 관련 상품 + 외부 구매 링크 표시. 각 룩/상품 카드에 **More Like This** 버튼 — 그 룩 기반 변주 3개 생성.
5. **저장·히스토리** — 프롬프트·룩·상품 결과 저장(기본 비공개), 다시 보기. **비로그인 시 히스토리/Save**: 빈 리스트 X. 가입 유도 화면(sample 룩 미리보기 + CTA) 노출. Save 버튼은 비로그인 시 "로그인하고 저장" 사전 표기 — 클릭 후 모달로 기대 깨지지 않음.
6. **공유** — 링크 공유, 이미지 저장/공유.
7. **인증** — Google → Kakao → Naver 순으로 소셜 로그인.
8. **운영자 어드민** — 룩/상품 링크 등록·수정·공개여부 관리 (최소 기능).

### Mini-action 3개 명세 (ADR-009 참조)

V0는 풀 멀티턴 채팅 X. 대신 싱글샷 워크스페이스 위에 3개 mini-action으로 "대화 가치 80%" 흡수:

| Mini-action | 트리거 위치 | 동작 |
|---|---|---|
| #1 다시 생성 | 결과 카드 위 | 같은 의도로 다른 룩 1-3개 |
| #2 조건 좁히기 | 정제 칩 클릭 ("더 캐주얼"·"색 변경"·"가격대 ↓") | 새 conversation turn으로 처리, AI 의도 보정 후 재검색·생성 |
| #3 More Like This | 각 룩/상품 카드 우측 하단 | 그 룩 기반 변주 3개 (스타일·색·핏 변형) |

## MVP 제외 사항 (Non-Goals)

- 자체 결제 / 물류·배송·환불·CS
- 사용자 이미지 업로드, 얼굴 합성, 가상 피팅
- 셀럽/인플루언서 이름·이미지 기반 AI 생성
- 전체 쇼핑몰 자동 크롤링, 실시간 재고/가격 동기화
- 공개 커뮤니티 피드 완성형 구현
- 모바일 앱 출시

## 디자인 방향

- 컨셉: **Editorial AI Studio** — 패션 에디터의 작업실 같은 AI 스타일 디렉터
- 원칙: "AI는 조용하게, 룩은 감각적으로, 상품은 명확하게"
- AI 챗봇보다 감각적, 쇼핑몰보다 덜 복잡, Pinterest보다 구매에 가까움
- Web-first MVP, mobile-ready: 국내 패션 소비의 모바일 중심성을 고려해 모바일 웹 핵심 플로우를
  V0 검증 범위에 포함. 데스크톱은 사이드바/워크스페이스/상품패널 3분할, 모바일은 세로 스크롤 +
  하단 바텀시트.

## Monetization (ADR-012 요약)

V0는 월구독 + 토큰 모델. **1회 검색 = 10토큰 = 룩 3개** (모든 generation 액션 동일 차감). 운영 quality는 OpenAI GPT Image 2 Medium 고정. 결제 모델:

| 플랜 | 가격 | 토큰 | 검색/월 | Saved | V0 단계 |
|---|---|---|---|---|---|
| free | 0원 | 가입 1회 10토큰 | 1회 | 5개 슬롯 | V0 Core |
| Pro | 9,900원/월 | 월 100 | 10회 | 5개 슬롯 | V0 Extended |
| Max | 19,900원/월 | 월 200 | 20회 | 무제한 | V0 Extended |

topup 단발 충전은 V0.5+ 후순위. 세부 매트릭스·마진·소진 UX는 `docs/ADR.md` ADR-012. 한국어 원본의 사용자 facing 정책은 `기획/I.F V0 PRD.md` §11.

## V0 Acceptance Criteria

비로그인 진입 → **Explore 피드에서 큐레이션 룩·데모 프롬프트 확인** → 로그인 → 프롬프트 입력 또는 칩 클릭(=새 turn) → AI 룩 1-3개 수신 (로딩 진행 텍스트 표시) → 룩 클릭으로 상품 패널 오픈 → 외부 구매 링크 클릭 → **More Like This로 변주 3개 생성** → 결과 저장(공개/비공개 선택) → 저장한 룩 다시 보기. 비로그인 사용자가 Save 클릭 시 "로그인하고 저장" 사전 표기로 기대 깨짐 없음. 운영자는 500개 curated look DB를 관리할 수 있다.
