# PRD: I.F (Intelligent Fashion)

> 전체 상세: `기획/I.F V0 PRD.md` 참조. 본 문서는 harness 워크플로우가 runtime guardrail로
> 읽기 위한 압축본이다. 원본과 충돌 시 원본이 우선한다.

## 목표

사용자가 텍스트 프롬프트로 상상한 패션 스타일을 AI 룩 이미지로 시각화하고, 그 룩과 어울리는
실제 구매 가능한 국내 패션 상품으로 연결한다. "원하는 스타일은 있지만 어떤 검색어로 찾을지
모르는" 탐색 문제를 해결한다.

## 사용자

- 한국 20-30대 여성 패션 소비자
- 무신사·29CM·지그재그·에이블리·네이버쇼핑·브랜드 자사몰을 오가며 온라인 쇼핑
- 인스타그램·유튜브·핀터레스트에서 영감을 받지만 탐색 피로를 느낌
- 1인 창업자가 AI 에이전트와 함께 실행 가능한 수준으로 V0 범위를 제한

## 핵심 기능 (V0 Core)

1. **프롬프트 입력** — 자유 텍스트 + 보조 칩(상황/계절/무드/예산/핏). 빈 입력창 막힘 방지.
2. **AI 룩 생성** — 프롬프트를 의도·상황·무드·아이템으로 해석해 1-3개 룩 이미지 생성.
   데모/인기 프롬프트는 사전 생성·검수 룩, 자유 프롬프트는 실시간 생성 (하이브리드).
3. **상품 추천/연결** — 룩 클릭 시 상품 패널 오픈. curated look DB(500개) 기반으로
   메인 추천 상품 조합 + 유사 상품 + 관련 상품 + 외부 구매 링크 표시.
4. **저장·히스토리** — 프롬프트·룩·상품 결과 저장(기본 비공개), 다시 보기.
5. **공유** — 링크 공유, 이미지 저장/공유.
6. **인증** — Google → Kakao → Naver 순으로 소셜 로그인.
7. **운영자 어드민** — 룩/상품 링크 등록·수정·공개여부 관리 (최소 기능).

## MVP 제외 사항 (Non-Goals)

- 자체 결제 / 물류·배송·환불·CS
- 사용자 이미지 업로드, 얼굴 합성, 가상 피팅
- 셀럽/인플루언서 이름·이미지 기반 AI 생성
- 전체 쇼핑몰 자동 크롤링, 실시간 재고/가격 동기화
- 공개 커뮤니티 피드 완성형 구현
- 모바일 앱 출시

## 디자인 방향

- 컨셉: **Editorial AI Studio** — 패션 에디터의 작업실 같은 AI 스타일 디렉터
- 원칙: "AI는 조용하게, 룩은 감각적으로, 상품은 명확하게"
- AI 챗봇보다 감각적, 쇼핑몰보다 덜 복잡, Pinterest보다 구매에 가까움
- Web-first MVP, mobile-ready: 국내 패션 소비의 모바일 중심성을 고려해 모바일 웹 핵심 플로우를
  V0 검증 범위에 포함. 데스크톱은 사이드바/워크스페이스/상품패널 3분할, 모바일은 세로 스크롤 +
  하단 바텀시트.

## V0 Acceptance Criteria

로그인 → 프롬프트 입력 → AI 룩 1-3개 수신 → 룩 클릭으로 상품 패널 오픈 → 외부 구매 링크 클릭 →
결과 저장(공개/비공개 선택) → 저장한 룩 다시 보기. 운영자는 500개 curated look DB를 관리할 수 있다.
